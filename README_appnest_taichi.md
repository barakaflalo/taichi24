## עדכון תמונות של תנועה
כדי להחליף/לעדכן תנועה: החלף את הקבצים בתיקיית `frames/NN_slug/` (אותם שמות: `f_1..f_N`, `m_1..m_N`).
אם מספר הפריימים משתנה — עדכן את הערך של אותו slug במפה `NF` בתוך `index.html`. פורמט WebP או PNG (המערכת מנסה קודם `.webp` ואז `.png`).

## פרסום ל-GitHub Pages
העלה את כל הקבצים לשורש הריפו. `.nojekyll` כבר כלול. בכל עדכון — העלה את `VERSION` ב-`sw.js`.
